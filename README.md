# HTML & CSS Login Page

## About
A beginner-level login page created using HTML5 and CSS3.

## Features
- Name input field
- Password input field
- Sign In and Reset buttons
- Forgot Password link
- CSS hover and focus effects
- Rounded borders and box shadow
- Responsive layout

## Technologies Used
- HTML5
- CSS3

## Learning Outcomes
Practiced HTML forms, CSS selectors, pseudo-classes, spacing, and box shadows.

## Note
This is a front-end UI project. It does not implement real user authentication.
